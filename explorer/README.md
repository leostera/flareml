# Trace explorer

React + React Flow, with Effect for cancellable loading and Effect Schema for
runtime decoding and inferred DTO types. Rust validates and projects all evidence;
the frontend does not implement model semantics.

## Run the embedded app

```sh
cargo run -- replay .fml/runs/<run-id> --ui --no-open
```

Open the **complete printed URL**, including its `#` session token. No Bun,
Node, frontend build, or internet connection is required for installed binaries.
Stop the native server with Ctrl-C. The URL grants access to this trace; keep it private.
The explorer loads all saved witnesses and merges exact execution prefixes into
a tree. Red paths lead to property violations; ordinary endpoints are not deadlock
findings. This is a tree of saved evidence, not the complete explored graph.
`--witness N` chooses the initial execution. Explicit model and trace paths also work.

Alternatively, `fml check model.fml --ui` opens the explorer when a property
violation is found. Artifacts are saved first; passing checks do not open a browser.
`--no-open` prints the URL instead. Closing the server preserves exit code 1 for
a violation (viewer errors exit 4).

## Navigating evidence

- **Traces** shows saved execution prefixes; **Entities** lists created actors at the current snapshot.
- Scrubbing the timeline updates the selected trace node and highlights changed actors.
- Nodes and the Entities list follow actual spawn order, including handler-created actors. Manual node positioning remains available.
- Each communicating actor pair has one connection: current sends animate toward the recipient; replies reverse that same line. Previously observed connections are dotted. Rewinding removes routes that have not happened yet. Multiple sends are counted and self-sends have a loop. These are observed routes, not permanent topology or inferred request/reply correlation. Setup and external submissions have no actor sender and remain in transition details.
- The right pane always shows **What changed** (named state fields and mailbox changes), above the selected entity's current state and messages.
- Values use model names and constructors, not JSON serialization wrappers. Raw evidence remains available in collapsed details.
- Clicking a property endpoint shows its source formula and validated failure context. Invariant failures refer to the final snapshot; temporal failures refer to the execution/loop, not necessarily a single state. This is not automated causal diagnosis.

## Frontend development

Use Bun 1.4.2. In one terminal, start the native command above and leave it running.
In another:

```sh
cd explorer
bun install --frozen-lockfile
FML_EXPLORER_ORIGIN=http://127.0.0.1:PORT bun run dev
```

Replace `PORT` with the native server's printed port. Open the Vite URL with the
native URL's **same `#TOKEN` appended**, e.g. `http://127.0.0.1:5173/#TOKEN`.
The proxy rewrites Host, but preserves bearer authorization and native session
validation. Do not put the token in an environment variable or query string.
Standalone Vite cannot supply evidence; it needs the native replay server.

## Validate and regenerate embedded assets

```sh
bun run typecheck
bun run test
bun run build
cd .. && cargo build && cd explorer
bunx playwright install chromium
bun run test:browser
```

Browser tests launch the actual native binary and use Chromium against its
embedded assets. Rebuild frontend assets **before** building Rust when changing
UI code. Commit `dist/`, including generated dependency license notices, along
with source and `bun.lock`. Rust never runs a JavaScript build.

`tests/fixtures/lossless.json` is generated by authoritative Rust replay. Regenerate
intentional projection changes with `FML_UPDATE_FIXTURES=1 cargo test --test explorer`
from the repository root, then run frontend schema tests.
